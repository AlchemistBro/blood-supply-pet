# Генерация физических ER

`task docs:er` обновляет `docs/architecture/er/*.md`; `task docs:er:check` сравнивает результат без записи.
Нужен Python 3.10+. Утилита не подключается к БД, не исполняет SQL и не запускает тесты.

Порядок источников соответствует `libs/runtime`: миграции messaging, refdata и конкретного сервиса.
Берётся только часть `Up`; строковые и dollar-литералы, комментарии и вложенные скобки учитываются при разборе.
Отображаются столбцы, первичные и внешние ключи. ALTER ADD COLUMN применяется к накопленной модели.
Кардинальность учитывает обязательность FK и объявленные в таблице PK/UNIQUE; отдельные уникальные индексы
не анализируются. CHECK, индексы, данные, функции и триггеры не отображаются.

Это ограниченный разбор используемого в репозитории DDL, а не универсальный PostgreSQL-парсер.
Неподдерживаемое изменение таблицы завершает генерацию ошибкой: прежде чем принять новую конструкцию,
нужно расширить разбор. SHA-256 исходников обнаруживает в том числе изменения ограничений, не показанных
на диаграмме. Проверка не доказывает валидность SQL или состояние работающей базы; их подтверждает
отдельный интеграционный прогон миграций.
