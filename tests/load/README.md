# Нагрузка трёх ролей

`roles.js` проходит OIDC через HTML-форму Keycloak и использует реальные cookie и CSRF BFF.
Сценарии: 20 операторов читают запас и задания, 20 врачей создают синтетические заявки и читают варианты,
10 аналитиков читают оценки. Разгон 30 с, затем 2 минуты при 50 VU и спад 30 с.
Порог NFR003: p95 экранов < 2 с именно в устойчивой фазе, ошибок < 1 %, успешных проверок > 99 %.

Запуск на отдельном синтетическом стенде: `task load`. Нужны k6 и уже поднятый стенд.
`BS_LOAD_WEB` меняет адрес, `BS_LOAD_PASSWORD` — демо-пароль, `BS_LOAD_INSECURE_TLS=1` допускает локальный
самоподписанный сертификат. `BS_LOAD_SYNTHETIC_ONLY=1` подтверждает выбор синтетического стенда.
Запуск создаёт заявки, но не выбирает варианты и не расходует запас.

`tests/load/results/summary.json` создаётся только выполненным прогоном и не коммитится.
После прогона сохраните параметры машины, версии, число единиц и реальную сводку в `docs/perf/`.
Сценарий не запускался по решению владельца; измерений NFR003 нет.

API сценария: [HTML forms](https://grafana.com/docs/k6/latest/examples/html-forms/),
[execution](https://grafana.com/docs/k6/latest/javascript-api/k6-execution/).
