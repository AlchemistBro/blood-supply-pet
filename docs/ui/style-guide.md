# Стиль интерфейса: государственная медицинская система

Цель: интерфейс, который узнаётся как служебная система государственной медицины: строгий, плотный, без декора,
понятный оператору у холодильника и врачу в приёмном. Никаких реальных гербов, названий ведомств и брендов.

## Принципы

1. **Сначала данные, потом оформление.** Таблицы плотные, числа выровнены по правой стороне, единицы измерения в заголовках.
2. **Одно действие — одна кнопка.** Главное действие экрана одно и синее. Опасные (отказ, отмена) — красные контурные, с подтверждением.
3. **Ответ в том же запросе.** Результат подтверждения показывается сразу, человеческим языком: «Закреплено 2 из 3 единиц. На недостающую единицу подбор предложит следующий источник».
4. **Всегда видно, насколько свежи данные.** Водяной знак «Запас обновлён 14:32» в шапке; при просрочке — жёлтая полоса предупреждения (NFR015).
5. **Работает без JavaScript.** HTMX только ускоряет: частичные обновления таблиц, SSE-статусы, модальные подтверждения.
6. **Формальный русский язык.** Глаголы в инфинитиве на кнопках («Подтвердить передачу»), статусы существительными («Перевозка запрошена»). Без восклицаний и эмодзи.

## Типографика

Системный шрифт: `system-ui, -apple-system, "Segoe UI", Roboto, "Helvetica Neue", Arial, sans-serif`; табличные цифры (`font-variant-numeric: tabular-nums`).
Размеры: базовый 14 px, таблицы 13 px, заголовок страницы 20 px полужирный, заголовки разделов 16 px. Межстрочный 1,4.

## Время, даты, объёмы

Время на экранах — московское, формат «23.10.2026 14:32»; машинное время в `<time datetime>` — UTC.
Допущение: Москва — фиксированная зона UTC+3 (перехода на летнее время нет с 26.10.2014), без базы часовых поясов
в образе (`services/web/internal/ui/format.go`). Изменится правило исчисления времени — меняется одна константа.
Объёмы — «1 200 мл» с неразрывными пробелами; длительности — «1 ч 12 мин», «3 сут».

## Сетка и компоненты

- **Шапка** (56 px, `--bs-primary`): слева эмблема-заглушка (круг с каплей, SVG) и название «АС распределения компонентов донорской крови»; по центру водяной знак; справа роль · клиника · логин · «Выйти».
- **Левая навигация** (240 px, `--bs-primary-dark`): пункты по роли, активный с белой полосой слева. На узких экранах сворачивается в кнопку.
- **Контент**: хлебные крошки, заголовок с главным действием справа, затем карточки/таблицы. Максимальная ширина 1440 px.
- **Таблица**: заголовок липкий, строки 36 px, зебра отключена, hover светло-серый, сортировка стрелками, пагинация внизу справа. Колонки чисел выровнены вправо.
- **Бейдж статуса O07**: прямоугольник 2 px радиус, текст 12 px, цвет по таблице ниже.
- **Форма**: подпись над полем, обязательные помечены «*», ошибка под полем красным, кнопки внизу слева: главная синяя, «Отмена» контурная.
- **Карточка задания**: двухколоночная: слева параметры (ключ–значение), справа действия и таймер «Срок подтверждения: 1 ч 12 мин» с жёлтым < 15 мин, красным истёк.
- **Модальное подтверждение**: `<dialog>` с заголовком-вопросом, кратким последствием и двумя кнопками.
- **Предупреждения** (полоса на всю ширину под шапкой): жёлтая «Данные запаса устарели (обновлено 2 ч назад)», красная «АИСТ-М недоступна: подтверждение временно невозможно».
- **Пустые состояния**: серый текст и одна кнопка действия.
- **Подвал**: версия сборки, «Демонстрационные данные и правила. Клиническое решение принимает врач.», ссылка на репозиторий.

## Статусы O07 в интерфейсе

| Статус | Текст | Цвет |
| --- | --- | --- |
| PENDING | Ожидает подтверждения | info |
| CONFIRMED | Подтверждено, единицы закреплены | success |
| TRANSPORT_REQUESTED | Перевозка запрошена | info |
| DISPATCHED | Отправлено | success |
| DELIVERED | Доставлено | success (приглушённый) |
| REJECTED | Отклонено | danger |
| EXPIRED | Не подтверждено в срок | neutral |
| CANCELLED | Отменено | neutral |
| BROKEN | Нарушено: единица выбыла | danger |

Дополнительные признаки: «Частично: 2 из 3» (warning), «Закрепление передаётся в АИСТ-М» (info, спиннер), «Подтверждено АИСТ-М» (success).

## Тексты результатов подтверждения

| Результат | Сообщение |
| --- | --- |
| Confirmed | «Закреплено N единиц. Готовьте к отправке.» / с недостачей: «Закреплено k из n. На оставшиеся m подбор предложит следующий источник.» |
| TaskWithdrawn | «Задание снято ({статус}). Не отправляйте единицы.» |
| UnitsUnavailable | «Выбыли единицы: {список}. Снимите их и подтвердите заново или включите «подтвердить частично».» |
| Rejected | «Все выбранные единицы выбыли в АИСТ-М. Задание отклонено, подбор предложит следующий вариант.» |
| UnitsTaken | «Единицы {список} уже закреплены за другим заданием. Выберите другие.» |
| ProtectedVolumeExceeded | «Передача опустит запас клиники ниже защищённого объёма. Можно подтвердить не больше {N} единиц.» |
| InvalidRequest | «{причина}» |
| SourceSystemUnavailable | «АИСТ-М не ответила. Задание остаётся в ожидании, повторите через минуту.» |

## Доступность

Контраст AA, фокус видимый (2 px `--bs-primary`), все интерактивные элементы доступны с клавиатуры, таблицы с `<th scope>`,
статусы не только цветом, но и текстом, `aria-live` для результатов и SSE-обновлений.
