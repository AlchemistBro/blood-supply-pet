# ADR-0015. Единый запуск сервиса и порядок миграций

Статус: принят, 20.10.2026.

## Контекст

Каждый сервис обязан одинаково читать конфигурацию, поднимать телеметрию, применять миграции, проверять JWT,
отдавать `/healthz`, `/readyz`, `/metrics`, `/openapi.yaml`, запускать ретранслятор outbox и мягко останавливаться
(CONTRIBUTING.md, «Архитектурные правила»). Копировать это в девять `main.go` значит получить девять расходящихся версий.

## Решение

- Пакет `libs/runtime` собирает всё общее. Сервис передаёт `Spec`: имя, модуль аудита, свои миграции, текст OpenAPI
  и функцию `Setup`, которая собирает зависимости, регистрирует маршруты и возвращает фоновых воркеров.
- Конфигурация только из переменных окружения с префиксом `BS_` (12-factor).
- Миграции goose объединяются из нескольких встроенных файловых систем. Нумерация: `00001–00099` платформа
  (outbox, inbox, `audit_local`, справочники), `00100+` сервис. Дубликат имени файла останавливает запуск.
  Параллельный запуск нескольких экземпляров защищает сессионная блокировка goose.
- После миграций сервис сидирует справочники из `libs/refdata` в одной транзакции (версия набора в `refdata_version`).
- Ретранслятор outbox запускается рантаймом, если задан `BS_KAFKA_BROKERS`; один активный экземпляр на базу держит
  advisory-блокировка.
- Проверка JWT включена всегда. `BS_AUTH_DISABLED=true` существует только для локальной отладки и пишет предупреждение
  в лог при каждом старте; в compose и Kubernetes он не задаётся.
- Отказ в доступе пишется в аудит (`ACCESS_DENIED`) той же библиотекой, которая пишет остальное (`Runtime.Deny`).

### Дополнение от 23.10.2026: сервис без базы

`Spec.NoDB = true` — сервис без PostgreSQL (имитаторы смежных систем `sim-*`): рантайм не подключается к базе, не применяет
миграции, не сидирует справочники в базу, не запускает outbox и ретранслятор; `BS_DB_URL` не нужен. Миграции у такого
сервиса запрещены: `Spec` с `NoDB` и `Migrations` не запускается. Заготовка: `tools/scaffold --no-db`.

## Последствия

- `main.go` сервиса занимает около тридцати строк, новый сервис добавляется шаблоном.
- Изменение общего поведения (например, добавление трассировки Kafka) делается в одном месте.
- Рантайм знает о `messaging`, `pgx`, `httpx`, `observability`, `refdata`; обратной зависимости нет, её запрещает `tools/archtest`.
