# ADR-0032: Проверка спецификации при подтверждении

Статус: принято. Дата: 24.10.2026.

Начальное подтверждение и замена должны одинаково соблюдать спецификацию
выбранного врачом варианта: вид, AB0/Rh, требования фенотипа и минимальную годность.
Проверка выполняется до обращения к inventory и повторно под блокировкой остатка.
Истёкшие единицы не учитываются в доступном остатке для проверки NFR013.

Требования фенотипа вида `K-` означают наличие заданных маркеров, а не буквальное
равенство всей записи единицы. Общий чистый парсер используется matching и
transfer. Отсутствующий или противоречивый маркер означает отказ. Для прежних
неструктурированных записей сохраняется только точное совпадение. Значения
фенотипа не включаются в тексты ошибок и аудит. Годность должна быть строго
позже минимального момента, включая проверку равенства границе.
