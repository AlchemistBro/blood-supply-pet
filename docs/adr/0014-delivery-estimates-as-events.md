# ADR-0014. Оценки времени доставки публикуются событием

Статус: принят, 20.10.2026.

## Контекст

FR026 и FR032 требуют время доставки при подборе источников (planning) и ранжировании вариантов (matching).
ИНТ-03a — запрос к C03. Синхронный запрос из цикла расчёта плана (100 клиник × источники) нарушил бы NFR002 и ADR-0004.

## Решение

`logistics-gateway` периодически (и по запросу через команду `RefreshDeliveryEstimates`) получает у C03 матрицу
оценок «источник → получатель» и публикует `DeliveryEstimatesPublished` в `logistics.events`. `planning` и `matching`
держат проекцию `delivery_estimate_projection` с `estimated_at`; устаревшая оценка (старше порога) помечается и в
объяснении решения указывается её возраст (NFR009). Для местного варианта время = 0.

## Последствия

Расчёт плана и подбор полностью локальные; C03 недоступна → используются последние оценки с пометкой «устарело»;
кэш оценок в `logistics-gateway` — его собственная таблица.
