# ADR-0026. Публичный синтетический стенд на Railway

Статус: принят для подготовки конфигурации, 24.10.2026. Создание платных ресурсов и публикация не выполнены.

## Решение

Сохраняются девять процессов приложения и три имитатора. Объединение audit/notification потребовало бы
отдельного запуска и проверки жизненного цикла; ради неподтверждённой экономии архитектуру не меняем.
Один PostgreSQL содержит отдельные базы и роли восьми сервисов и Keycloak. Web и имитаторы своих баз не имеют.
Kafka — один KRaft-брокер с томом, письма остаются в закрытом Mailpit. Это демонстрационный профиль без HA.

Публичный HTTPS-домен принадлежит edge: `/` ведёт в web, `/oidc/realms/blood-supply/` и `/oidc/resources/`
в Keycloak. Административные пути Keycloak, метрики, API сервисов и dev-маршруты имитаторов наружу не выводятся.
У web, Keycloak и остальных сервисов публичных доменов и TCP-прокси нет. TLS завершается на Railway;
edge перезаписывает заголовки прокси. Исходящий служебный обмен идёт по частной сети.

В Railway используются готовые образы ghcr.io, включая образ edge и оптимизированный Keycloak с realm-шаблоном.
Сборка выполняется существующим GitHub Actions после отдельного разрешения на push. Для воспроизводимости
перед публикацией фиксируется один SHA-тег всех образов; наличие образов проверяется отдельно.
JSON профиля — перечень настроек для оператора, а не вымышленный формат импорта проекта Railway.

Секреты web/services, cookie, K1 и ролей БД создаются отдельно; K1 получает только inventory и matching.
Демо-учётки известны посетителям, их данные и правила синтетические. Номер случая всё равно шифруется.
Начальное наполнение выполняется отдельной задачей через API. Автоматическое удаление данных при каждом
старте запрещено: перезапуск контейнера не означает согласованный сброс всего стенда.

## Ограничения и следующий шаг

Профиль и порядок запуска готовятся локально. Бюджет, аккаунт Railway и разрешение на публикацию образов
ещё не предоставлены. До этого не создаются платные сервисы и не придумывается публичный URL.
Текущие тарифы сверены с [официальной страницей](https://railway.com/pricing) 24.10.2026:
минимум Hobby не является ценой всего стенда. При 3 ГБ постоянной памяти только RAM за 30 дней составляет
примерно $30 по опубликованной ставке $0.00000386/ГБ·с; CPU, диски и трафик оплачиваются отдельно.
Это расчёт по предположению, не измерение потребления проекта и не согласованный бюджет.

Ежесуточный согласованный сброс, закрытая dev-панель и публичный nightly smoke остаются критериями
публичной приёмки. До их реализации и реального прогона профиль не считается готовым публичным стендом.
