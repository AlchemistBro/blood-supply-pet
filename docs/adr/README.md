# Архитектурные решения (ADR)

Формат: контекст, решение, последствия, условия пересмотра. Статусы: предложен → принят → заменён ADR-NNNN.
«Запланирован» — номер выдан, документ появится вместе с пакетом своего этапа.
Новый ADR обязателен для любого отклонения от канона `docs/domain/` или от принятого ADR.
