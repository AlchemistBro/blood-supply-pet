# ADR-0001. Go вместо Java 21 / Spring Boot

Статус: принят, 20.10.2026.

## Контекст

Учебные документы (ПР4 DDD, ПР6 DDD) выбирают Java 21, Spring Boot, Spring Modulith. Java-прототип саги уже существует.
Владелец проекта хочет публичный пет-проект на Go, демонстрирующий архитектурное мышление, с прицелом на реальный прод.

## Решение

Реализация на Go 1.27. Канон предметной области (объекты, требования, статусы, формулы) переносится без изменений.
Java-прототип используется как исполняемая спецификация саги: его тесты переносятся первыми.

## Последствия

- Плюсы: один статический бинарник на сервис, образы distroless ~20 МБ, быстрый старт в k8s, простые горутины для воркеров
  (relay, таймеры, consumer), `internal/` закрывает границы сервисов компилятором.
- Минусы: нет Spring Modulith (архитектурные тесты пишем сами в `tools/archtest`), нет Flyway (goose), нет JPA (sqlc).
- Расхождение с учебными документами объясняется в README: «архитектура и канон из документов, язык прототипа — Go».

## Условия пересмотра

Нет: решение владельца.
