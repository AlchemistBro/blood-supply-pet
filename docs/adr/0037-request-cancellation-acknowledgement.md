# ADR-0037. Завершение отмены заявки по результату transfer

Статус: принят, 24.10.2026.

Проекция matching может отставать: врач отправил отмену, когда источник уже зарегистрировал отправку.
По локальной проекции нельзя объявлять всю заявку отменённой и закрепление снятым.

Для выбранного удалённого варианта matching сохраняет `CANCELLATION_REQUESTED` и команду отмены одной
транзакцией. Повтор не создаёт команду заново. transfer ставит надгробие, отменяет доступные для отмены
O07 и публикует `RequestCancellationProcessed` с идентификаторами уже отправленных или доставленных O07.
При пустом списке matching завершает `CANCELLED` и публикует событие отмены заявки. Иначе сохраняет
`CANCELLATION_REJECTED`: дальнейшие источники не создаются, отправленная часть остаётся видимой.
Вариант, ещё не выбранный, и местный выбор отменяются сразу: внешних обязательств у них нет.

Оба промежуточных исхода подавляют автоматическое продолжение заявки. Запись результата и outbox
идемпотентны через inbox. Статусы O07 и запрет отмены отправленного груза не меняются; синхронных вызовов нет.
Номер случая не входит в результат отмены. Интерфейс показывает ожидание и отказ отмены явно.
