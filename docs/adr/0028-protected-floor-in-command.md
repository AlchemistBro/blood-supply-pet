# ADR-0028: Порог источника в команде открытия задания

Статус: принято. Дата: 24.10.2026.

## Контекст

`ProtectedVolumeCalculated` проходит через inventory, а `OpenObligation` поступает
напрямую в transfer. Порядок доставки между топиками Kafka не гарантирован.
Подтверждение может опередить обновление защищённого остатка из того же плана.

## Решение

Необязательное поле `protected_floors` команды содержит пороги в единицах по
источникам для данного вида компонента, без уже подтверждённых обязательств
(семантика ADR-0019). Planning передаёт порог основного и запасных источников.
Transfer сохраняет пороги с заданием и переносит их при переходе к запасному
источнику. Под блокировкой source_stock подтверждение использует максимум
актуальной проекции и порога задания. Резерв вычитается отдельно, как прежде.

Старые команды без поля сохраняют прежнюю семантику. Поле не содержит K1.
Повторный расчёт не уменьшает порог уже открытого задания; это намеренный
консервативный отказ, пока оператор не отменит или не пересчитает задание.

## Последствия

Задержка ретрансляции защищённого остатка не позволяет подтвердить задание
ниже порога его плана. Более высокий порог новой проекции также сохраняется.
Это не заменяет проверки статуса единиц и блокировки остатка.
