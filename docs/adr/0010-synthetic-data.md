# ADR-0010. Данные и клинические правила синтетические

Статус: принят, 20.10.2026 (перенос ADR-007 прототипа).

## Контекст

Реальных данных АИСТ-М, прогнозов ЧС и утверждённых заказчиком правил подбора нет и не будет. Нормативные основания
правил (кроме Постановления Правительства РФ № 641 от 14.05.2025) не проверены. Проект публичный.

## Решение

- Все клиники, районы, единицы, нормативы, доли, прогнозы — синтетические, генерируются `libs/testdata` детерминированно.
- Справочник правил O15 заполняется демонстрационными правилами с `basis_document = "ДЕМО: синтетическое правило"`;
  структура (условие, замена, исключение, приоритет, основание, версия, срок действия) настоящая.
- В UI и README явная пометка: «данные и правила демонстрационные, клинические решения принимает врач».
- Номер донации и исходный код единицы АИСТ-М не публикуются в событиях (суррогат `unit_id`).
- Содержание клинических правил не придумывается «как настоящее»: нет утверждений о совместимости групп, кроме
  общеизвестного и явно помеченного как демо.

## Последствия

Проект показывает механизм, а не медицинскую истину; заказчик при внедрении заменяет содержимое справочника и данные.
