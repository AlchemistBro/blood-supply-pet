# ADR-0030: Отмена заданий пересчитанного плана

Статус: принято. Дата: 24.10.2026.

## Контекст

При пересчёте planning знает идентификаторы предложений, но может ещё не получить
`ObligationOpened`. Отмена только известных O07 оставляет поздно открытые задания.
Отменять подтверждённые передачи из-за пересчёта плана также нельзя.

## Решение

Команда `CancelRequestObligations` с `request_id`, причиной и `only_pending`
записывает в transfer надгробие заявки/плана и отменяет существующие задания.
Planning посылает её для предыдущих планов с `only_pending=true`.
Подтверждённые задания сохраняются. Поздние `OpenObligation` и переходы к
запасному источнику для отменённого плана не создают новых O07.

Создание, пакетная отмена и истечение срока сначала блокируют ключ заявки,
затем все затронутые остатки в порядке ключей и обязательства. Подтверждение
сохраняет порядок остаток → обязательство. Повтор команды отсекает inbox.
Надгробие, изменения O07, события и аудит фиксируются одной транзакцией.

## Последствия

Перестановка команд разных партиций не возрождает старый план. Пересчёт должен
использовать новый идентификатор плана. Нельзя повторно открывать задания
отменённой заявки под прежним request_id.
