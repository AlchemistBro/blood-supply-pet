# ADR-0007. Интерфейс: Go SSR + HTMX

Статус: принят, 20.10.2026.

## Контекст

Документы выбирают React + TypeScript. Владелец просит «простенький гос-больничный интерфейс» и Go без Node в сборке.
Экранов немного (около 20), они формы и таблицы; живого обновления требуют статусы O07 и время обновления запаса.

## Решение

Сервис `web` рендерит страницы `html/template` (встроены через `embed`), HTMX 2.x вендорится в `static/vendor`, стиль —
собственный CSS по `docs/ui/style-guide.md` (визуальный язык государственных медицинских систем: плотные таблицы,
синяя шапка, строгая типографика, бейджи статусов). Живые статусы — SSE-эндпоинт `web`, подписанный на `transfer.events`.
Все формы работают без JavaScript; HTMX только улучшает.

## Последствия

- Один бинарник, никаких сборщиков; скриншоты и Playwright-тесты легко.
- `web` — BFF: агрегирует вызовы сервисов, держит сессию, пишет `READ_PATIENT_CASE` в аудит.
- Отклонение от учебных документов зафиксировано; при желании SPA можно добавить поверх тех же API сервисов.
