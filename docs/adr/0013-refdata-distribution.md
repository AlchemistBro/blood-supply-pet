# ADR-0013. Справочники как статический набор `libs/refdata`

Статус: принят, 20.10.2026.

## Контекст

Схема `ref` ПР6 (клиники, районы, виды компонентов, группы крови, срочность) нужна всем сервисам. Отдельный
`reference-service` добавил бы сервис и сетевую зависимость на каждый запрос; общая таблица нарушила бы ADR-0005.

## Решение

Справочники лежат в коде (`libs/refdata`, JSON + Go-типы + валидация) и сидируются в базу каждого сервиса миграцией
`ref_*`. Версия набора — поле `refdata_version` в каждой базе. Изменение справочника — новая версия набора и новая миграция.
Для прода предусмотрено событие `ReferenceDataChanged` (контракт зарезервирован, реализация вне плана).

## Последствия

Справочники одинаковые у всех сервисов без сети; клиники и районы в демо — 100 и 12 синтетических (ADR-0010).
