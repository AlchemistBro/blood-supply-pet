# ADR-0008. uuid v7 для агрегатов, snake_case, имена из словаря ПР6

Статус: принят, 20.10.2026.

## Контекст

DDL ПР6 использует `bigint GENERATED ALWAYS AS IDENTITY` и имена таблиц в CamelCase в кавычках (`inventory."Unit"`).
В распределённой системе нужны идентификаторы, которые можно создавать на клиенте (идемпотентность команд, ключи сообщений),
а кавычки в именах неудобны в pgx/sqlc.

## Решение

- Агрегаты и сообщения: `uuid` v7 (упорядочен по времени, дружелюбен к B-tree).
- Справочники: естественные коды (`O-`, `RBC`, `URGENT`); клиники и районы — `bigint` из `libs/refdata`.
- Таблицы и столбцы — snake_case, имена сущностей и полей совпадают со словарём данных ПР6 (`unit`, `stock_norm`, `clinical_request`…).
- Соответствие ПР6 ↔ реализация ведётся в `docs/architecture/data-model.md`.

## Последствия

Трассируемость к учебным документам сохраняется по именам; суррогат `aist_unit_code` наружу не публикуется (ADR-0010).
