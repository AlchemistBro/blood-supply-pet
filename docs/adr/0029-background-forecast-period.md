# ADR-0029: Фоновая потребность на горизонт прогноза

Статус: принято. Дата: 24.10.2026.

## Контекст

Оценка demand содержит объём за выбранный аналитиком период. C02 присылает
прогноз на несколько часов или дней. Перенос месячного объёма целиком на этот
горизонт завышает целевой и защищённый запас, а требование точного совпадения
времени делает прогноз с текущим временем несовместимым с календарным CSV.

## Решение

При построении плана с прогнозом его период должен полностью входить в период
опубликованной оценки demand. Фоновый объём каждой строки умножается на отношение
длительностей периодов. Допущение равномерного расхода является демо-правилом,
а не медицинской моделью. Норматив не масштабируется. План без прогноза использует
весь объём опубликованной оценки. Снимок входов хранит уже приведённый объём,
идентификатор и версию исходной оценки и прогноз. Экстраполяция за пределы
опубликованного периода запрещена: аналитик публикует оценку нужного периода.
