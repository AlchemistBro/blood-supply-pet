Цель: подтвердить работу системы измерениями, оформить документацию и выпустить проверенные образы.

## Подтверждённая базовая приёмка

- [x] CI: линтеры, генерация, unit/race, PostgreSQL/Kafka, контракты, безопасность и сборка.
- [x] Compose E2E: десять сценариев, включая 50 конкурентных подтверждений, повторы, паузу Kafka и отказы gateway.
- [x] Финальный k6: 50 VU; GitHub на четырёх CPU — p95 685,71 мс, ошибок 0; локально сервисы и генератор на общих двух CPU — p95 994,48 мс, ошибок 0,48%. Все пять порогов пройдены. Это p95, не максимум каждого запроса.
- [x] Алгоритм плана для NFR002: локальные и GitHub-бенчмарки; HTTP/БД этим не измеряются.
- [x] Проверка образов приложения Trivy: 12 образов без HIGH/CRITICAL; сторонние образы платформы в прежний результат не входят.
- [x] Авторизация, клиники, CSRF, заголовки безопасности, отсутствие персональных полей в контрактах проверены тестами.
- [x] Вход трёх ролей, повтор CSV и расчёт потребности проверены в Chrome.
- [x] C4/UML/BPMN/ER и ADR сверены; экспорт SVG прошёл в workflow документации, в main добавлены BPMN AS IS / TO BE.
