Цель: проект готов показывать: нагрузка и хаос подтверждены, безопасность проверена, схемы финальные, README с демо.

## Чеклист

Состояние 24.10.2026: подготовлены k6-сценарии трёх ролей с реальными OIDC/cookie/CSRF, отдельный workflow нагрузки,
50 конкурентных подтверждений одной единицы, пауза Kafka на 60 с, запуск сценариев устойчивости `task chaos`.
Добавлены `task seed` и `task seed:kind` через HTTP, с отдельной ограниченной операцией демо-нормативов.
Обновлены README, английское описание, схемы компонентов planning/matching и UML агрегатов.
`task docs:er` строит физические ER восьми баз по Up-миграциям без исполнения SQL;
`task docs:er:check` сверяет сохранённые схемы в CI. Работающий PostgreSQL этой проверкой не проверяется.
`task docs:diagrams` и docs workflow готовят экспорт Mermaid/BPMN в SVG с перечнем исходников
и артефактом `architecture-svg`. Четыре BPMN статически сверены по XML, ссылкам и DI;
устаревшие аннотации о шифровании, ИНТ-05 и отмене приведены к реализации. Экспорт браузером не выполнялся.
Сборка и статические проверки выполнены. После уточнения владельца обычные тесты пройдены,
интеграционные проверки PostgreSQL пройдены без Docker с отдельными временными базами:
Последний прогон на Go 1.27.3: 73 пакета, 1839 успешных тестов/подтестов, 15 пропусков Kafka.
Фитнес-тест 50 подтверждений одной единицы прошёл; это не e2e на стенде.
[Результаты последнего прогона](../architecture/security-local-2026-10-24.md).
Нагрузка на стенд, деплойные сценарии, хаос и браузерные снимки не запускались.
Для отказа Keycloak подготовлена проверка web: действующий токен сохраняет доступ до своего срока,
ошибка раннего refresh не продлевает сессию, новый вход получает понятную страницу 503 и Retry-After.
Проверка прошла в обычном прогоне. Воздействия на процессы реального стенда,
публикация релиза и фактические измерения остаются открытыми.
