# Этап 10. Публичный демо-стенд на Railway

Статус: заготовка, начинается после этапа 9. Решение владельца от 20.10.2026: демо выкладывается на Railway.
Цель: рабочий публичный URL, по которому можно пройти демо-сценарий из README без установки чего-либо.

## Что нужно учесть заранее

Railway запускает сервисы из Docker-образов или репозитория и даёт управляемый PostgreSQL. Kubernetes-манифесты
из `deploy/k8s` там не применяются, поэтому стенд описывается отдельно, а образы берутся из ghcr.io (этап 1+).
Актуальные возможности и цены Railway проверить на момент этапа: от них зависит, сколько сервисов влезет в бюджет.

## Решения, которые надо принять в начале этапа (ADR-0015)

| Вопрос | Варианты | Предварительная рекомендация |
| --- | --- | --- |
| Профиль нагрузки | а) все 9 сервисов и 3 имитатора; б) облегчённый: `notification` и `audit` в одном процессе (разрешено ADR-0002), имитаторы в одном процессе | б), чтобы уложиться в бюджет |
| Kafka | своя в контейнере (KRaft, один брокер) или облегчённая замена (Redpanda) | Один брокер в контейнере с томом; контракты не меняются |
| Keycloak | в контейнере с импортом realm | Да, `start --optimized`, база `keycloak` в том же Postgres |
| PostgreSQL | один управляемый экземпляр, база и роль на сервис (ADR-0005 сохраняется) | Да |
| Доступ | публичный URL только у `web`; ИНТ-02 закрыт токеном; остальное во внутренней сети Railway | Да |
| Данные | демо-сид при старте, ежесуточный сброс | Да, чтобы стенд не загрязнялся |

## Чеклист

- [ ] ADR-0015 «Демо-стенд на Railway» принят, профиль и бюджет оценены.
- [ ] Конфигурация сервисов Railway (`deploy/railway/`): переменные `BS_*`, порядок запуска, health checks по `/readyz`.
- [ ] Образы только из ghcr.io (теги `edge` или `vX.Y.Z`), без сборки на Railway.
- [ ] Keycloak: realm с демо-пользователями, redirect URI на публичный домен, HTTPS.
- [ ] Защита публичного стенда: лимиты частоты, dev-панель имитаторов доступна только после входа демо-ролью, без реальных данных.
- [ ] Ежесуточный сброс и пересев демо-данных (cron-задача).
- [ ] Баннер на всех экранах стенда: «Демонстрационная система. Данные и правила синтетические».
- [ ] README: ссылка на стенд и учётные записи демо; бейдж доступности.
- [ ] Smoke против публичного URL в CI (nightly): вход, подтверждение задания, статус обновился.

## Критерий выхода
Публичный URL открывается, вход через Keycloak работает, демо-сценарий из README проходит за 5 минут, nightly smoke зелёный.
