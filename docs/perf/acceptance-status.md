# Состояние приёмочных измерений

Дата: 24.10.2026.

По решению владельца тесты, Docker, Testcontainers, Kubernetes и сценарии отказов на рабочей машине
не запускаются. Ниже зафиксирована подготовка проверок, а не результаты их выполнения.

| Проверка | Подготовленный сценарий | Результат |
| --- | --- | --- |
| NFR002: план 100 клиник / 100000 единиц | `task bench:plan` | Не измерялось |
| NFR003: p95 интерфейса при 50 пользователях | `task load`, реальные сессии OIDC и CSRF, устойчивая фаза | Не измерялось |
| NFR004: конкурентное закрепление | Фитнес-, интеграционные и e2e-тесты transfer | Не запускались |
| ИНТ-05: потерянный ответ, повтор, снятие | Интеграционные inventory / matching / sim-aist | Не запускались |
| Условия перевозки и запрет использования | Домен и интеграционные transfer, sim-logistics | Не запускались |
| Доставка уведомлений и детектор инцидентов | Интеграционные notification / audit | Не запускались |
| Восстановление проекций без повторных заданий | Интеграционные planning | Не запускались |
| Изоляция Kubernetes | `task k8s:network-check` | Не запускалось |
| Готовность / вход / отказ чужой роли | `task k8s:smoke` | Не запускалось |
| NFR006 / NFR007: восстановление БД | `task k8s:drill` | Не измерялось |

Доступные проверки: сборка Go, vet с тегами integration/e2e, линтеры, актуальность генерации,
совместимость схем, матрица прав, Bash-синтаксис, actionlint и kustomize/k8scheck.
После разрешения запуска необходимо выполнить один общий прогон и заменить строки таблицы ссылками
на реальные артефакты CI. Учение PITR само создаёт отдельный отчёт с измерениями только после выполнения.
