Доступные проверки: сборка Go, vet с тегами integration/e2e, линтеры, актуальность генерации,
совместимость схем, матрица прав, Bash-синтаксис, actionlint и kustomize/k8scheck.
Обычный прогон `go test -count=1 -p 2 -parallel 4 -timeout 3m ./... ./libs/testdata` прошёл: 73 пакета с тестами.
Миграции `libs/pgx`, справочники `libs/refdata`, проверка изоляции/удаления временной базы, аудит и
расчёт/публикация/отклонение оценки demand с откатом при ошибке пакетной записи проверены на внешнем PostgreSQL.
Итоговый прогон `-tags integration` по `./libs/... ./services/...` прошёл на отдельном локальном PostgreSQL 16.15:
72 пакета с тестами, 1258 успешных тестов/подтестов, 15 пропусков из-за отсутствия Kafka;
ещё 65 пакетов не содержат тестов. Временных баз после завершения — 0.
[Команды, исправления и ограничения](postgres-local-2026-10-24.md).
Kafka без внешнего брокера явно пропускается по `BS_TEST_NO_DOCKER=true`, её работоспособность этим не подтверждена.
Деплойные измерения и полный сквозной сценарий остаются отдельной непроведённой приёмкой.
